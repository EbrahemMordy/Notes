# Explanation
## If
```python
if x<y:
	print()
```
## Elif
```python
elif x>y:
```
## Else
```python
else:
	print()
```
> you can have ranges compare in python

```python
return True if cond else false
```
## Match
```python
match var:
	case "" | "" | :
		ddd
	case "":
		ddd
	case _
		default
```
